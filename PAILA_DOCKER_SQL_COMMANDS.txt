SQL files kept for deployment
-----------------------------

1. database/schema.sql
   Creates the database tables and inserts required base data:
   roles, super admin, demo guide accounts, and guide profile records.

2. database/package_data.sql
   Inserts the Nepal travel package/tour data using the same fields as the
   admin package form:
   title, location, price, duration, description, category, difficulty,
   max_group, highlights, image, best_season, altitude_max,
   permit_requirements, itinerary, inclusions, exclusions, is_featured,
   and created_by.


1. Start the project
--------------------

docker compose up -d


2. Check containers
-------------------

docker ps


3. Open MySQL shell
-------------------

docker exec -it nepal_tours_db mysql -unepal_user -pnepal_pass nepal_tours

Root shell if needed:

docker exec -it nepal_tours_db mysql -uroot -prootpassword nepal_tours


4. Import schema only
---------------------

PowerShell:

Get-Content -Raw .\database\schema.sql | docker exec -i nepal_tours_db mysql -unepal_user -pnepal_pass nepal_tours

Command Prompt:

cmd /c "type database\schema.sql | docker exec -i nepal_tours_db mysql -unepal_user -pnepal_pass nepal_tours"


5. Import package data only
---------------------------

PowerShell:

Get-Content -Raw .\database\package_data.sql | docker exec -i nepal_tours_db mysql -unepal_user -pnepal_pass nepal_tours

Command Prompt:

cmd /c "type database\package_data.sql | docker exec -i nepal_tours_db mysql -unepal_user -pnepal_pass nepal_tours"


6. Full fresh local rebuild
---------------------------

Warning: this deletes the local Docker database volume.

docker compose down -v
docker compose up -d

Docker automatically imports:
database/schema.sql
database/package_data.sql

Wait around 20-40 seconds for MySQL to initialize, then open:
http://localhost:8080


7. Check tables
---------------

docker exec -it nepal_tours_db mysql -unepal_user -pnepal_pass nepal_tours -e "SHOW TABLES;"


8. Check admin users
--------------------

docker exec -it nepal_tours_db mysql -unepal_user -pnepal_pass nepal_tours -e "SELECT users.id, users.username, users.email, roles.name AS role FROM users JOIN roles ON roles.id = users.role_id WHERE users.role_id IN (1, 2);"


9. Check guide profiles
-----------------------

docker exec -it nepal_tours_db mysql -unepal_user -pnepal_pass nepal_tours -e "SELECT users.id, users.email, guide_profiles.full_name, guide_profiles.specialties FROM users JOIN guide_profiles ON guide_profiles.user_id = users.id WHERE users.role_id = 4;"


10. Check package count by category
-----------------------------------

docker exec -it nepal_tours_db mysql -unepal_user -pnepal_pass nepal_tours -e "SELECT category, COUNT(*) AS total FROM tours GROUP BY category ORDER BY category;"


11. Check all packages
----------------------

docker exec -it nepal_tours_db mysql -unepal_user -pnepal_pass nepal_tours -e "SELECT id, title, location, category, price, duration, is_featured FROM tours ORDER BY id;"


12. Export a backup
-------------------

PowerShell:

docker exec nepal_tours_db mysqldump -unepal_user -pnepal_pass nepal_tours > .\paila_backup.sql


13. Import a backup
-------------------

PowerShell:

Get-Content -Raw .\paila_backup.sql | docker exec -i nepal_tours_db mysql -unepal_user -pnepal_pass nepal_tours
